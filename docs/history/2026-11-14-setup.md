## Lessons
- F-API-003: litres per sales unit = catalog price / comparison price (cross-check) and = amount per base unit x pack size (derivation); they agree on all 9 milks.
- F-API-004: the API does not enforce `closingTime`; Quote must.
- F-API-005: partial stock (698 of 1,000 units) and "not deliverable" (`464440`) occur naturally in the milk request.
- F-API-007: do not send the API key to the webshop host; it blocks scripted clients (Cloudflare 1010).
- The API key was sent once to the webshop host by mistake before the base URL was checked; it was blocked before reaching an application and is a synthetic challenge key. Always read the target host before sending a credential.
